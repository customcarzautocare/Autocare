This admin is built specifically for the current customcarzautocare/Autocare repository. It edits products.json and site.json only.

Products

Every product in the current products.json is loaded. You can control category, subcategory, display order and collection flags.

Display order: 1 appears first, then 2, 3, etc. Products without an order are placed after ordered products. Image paths are saved as relative paths such as assets/products/photo.jpg, never as raw.githubusercontent.com URLs.

Categories & Subcategories

The category selector used by every product is generated from your current site categories plus categories already used by your products. Saving categories updates site.json; product categories are not silently changed.

Website Content

Edit the current values stored in site.json. These changes do not rewrite index.html.
