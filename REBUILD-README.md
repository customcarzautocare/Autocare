2. Replace the old root `index.html`, `robots.txt`, and `sitemap.xml`.
3. Add the generated directories: `shop/`, `categories/`, `category/`, `products/`, `services/`, `about/`, `reviews/`, `contact/`.
4. In GitHub Pages, use GitHub Actions as the publishing source if using `.github/workflows/pages.yml`.
